# Verified Conversation Examples

This folder contains real conversation transcripts captured from the running application.

The challenge requires 3–5 examples, including at least one non-trivial interaction.

Suggested coverage:
1. Product search with price and stock information.
2. Product recommendations under a customer budget.
3. Order status and tracking lookup.
4. Store return or warranty policy question.
5. An out-of-scope question.

Only add transcripts that were actually run and verified. Do not fabricate conversations or model outputs.

For each example, record:
- The customer prompt.
- The actual agent response.
- Whether the answer was grounded in the supplied data.
- Any relevant tool or retrieval behavior.

Remove personal or sensitive information before committing transcripts.
